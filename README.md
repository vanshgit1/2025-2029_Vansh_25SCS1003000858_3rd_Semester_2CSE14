## 📌 About the Internship

The internship focused on building a strong practical foundation in Machine Learning and Artificial Intelligence. It applied these concepts to real-world computer vision problems like image classification, object detection, and visual search application workflows. 

**Organization:** DecodeLabs is a government-registered digital learning and technology enterprise operating under the theme "Your Digital Lab". The program bridges the gap between academic theory and industry workflows by providing engineered, hands-on project experience.

---

## 🎯 Objectives

- Understand the first principles of machine learning to build image recognition and classification models.
- Learn the fundamentals of object detection and integrate detectors into active applications.
- Train, evaluate, and optimize custom models for computer vision tasks.
- Build intelligent features such as product image search using on-device or cloud-based detection.
- Detect objects in static images and live feeds for visual search environments.
- Understand backend integration concepts for AI-powered mobile or web applications.

---

## 🗓️ Internship Curriculum & Methodology

| Phase | Module / Focus Areas | Description |
|---|---|---|
| 1 | Foundations of ML & Neural Networks | Foundational concepts of machine learning, from first principles through to building models for image recognition and classification. |
| 2 | Object Detection Basics | Basics of object detection and integrating pretrained object detectors into applications. |
| 3 | Custom Models & Product Image Search | Training custom models and building product image search features using detection on static images and live feeds. |
| 4 | Integration & Classification | Backend integration concepts, custom image-classification models, and integrating a classifier into an application. |
| Final | Project Submission & Evaluation | Final project submissions, mentor evaluation, and award of Certificate of Completion. |

> **Note:** There was no stipend associated with this internship.
